ワールド

      
MoreDimensions で1つのサーバーに好きなだけワールドを追加し、ワールドごとにルールを決められます。プレイヤーは /dim（またはコンパスを使う）でメニューを開いて移動し、ワールドごとに最後にいた場所へ戻ります。追加・削除・リセットは再起動で反映されます（参加者は待機サーバー経由で自動で戻ります）。ルールや表示の変更はすぐ反映できます。

実験的機能（このワールド）

        
ワールドの level.dat の experiments です。Script API の beta 版モジュール（例: @minecraft/server の beta）は「Beta APIs」が必要です。反映時、サーバー停止中に書き換えます（元の level.dat は .levikit-bak に保存）。

        

        

      

      

        
Script API の許可モジュール

        
config/default/permissions.json の allowed_modules です。@minecraft/server-net（HTTP 通信）や @minecraft/server-admin（変数・シークレット）は BDS だけで使えるモジュールで、ここで許可したものだけスクリプトから読み込めます。パックごとの変数・シークレットは「ファイル」の config/<パックのUUID>/variables.json / secrets.json に書きます。

        

      

      

        
反映・コマンド

        

          
          
          
          
        

        
スクリプトだけを直したときは /reload で十分です（パックの追加・削除・実験的機能の変更は再起動が必要）。スクリプトのエラーはコンソールに [Scripting] として出ます。

      

    


    

      
マップ / タイムマシン

      
ワールドを上空から見た地図を、参加したまま作ります。過去のバックアップの地図に切り替えたり、2つの時点で変わったチャンクを色付けしたりできます。範囲を選んで「この範囲だけ過去に戻す」と、荒らされた場所だけを元に戻せます（オーバーワールドも可・他の場所はそのまま）。

      

        

          
          
          
          
          
          
        

        
地図がありません。「📷 今の状態を撮る」を押してください。

        

          ドラッグで移動・ホイールで拡大・Shift+ドラッグで範囲選択
          
          
          
          
          
        

        

      

      

        
高品質マップ（PapyrusCS）

        
統合版用の定番マップレンダラー PapyrusCS（Apache-2.0）で、拡大縮小できるタイル地図を作ります。2回目からは変わったチャンクだけ描き直します。上のワールド選択を使います。

        

      

    


    

      
ワープ / ポータル

      
ワープはどのワールドからでも /warp 名前 で飛べる地点です（ゲーム内では OP が /setwarp 名前 でその場に作れます）。ポータルは範囲に入ると別のワールド/ワープへ移動させます（ゲーム内では /dimportal pos1・pos2・create 名前 行き先）。行き先は world:ID（スポーン）・last:ID（最後にいた場所）・warp:名前。

      

        
ワープ

        
名前ワールドx / y / z向き説明OP専用

      

      

        
ポータル

        
有効名前ワールド角1 x / y / z角2 x / y / z行き先メッセージ

      

      

    


    
    

      
バックアップ

      
「ホット」バックアップはプレイヤーが遊んだまま取得します（save hold → 整合性のあるファイル長でコピー → save resume）。復元はプレイヤーを待機サーバーへ逃がしてから差し替え、自動で戻します。復元前のワールドは自動で退避バックアップになります。

マルチプロトコル (Glacie + ProtocolLib)

        
サーバー本体と異なるバージョンのクライアントを接続させる LeviLamina 用 Mod。新しいクライアント版への対応は ProtocolLib の更新で入ります。
