# GeoUI のタイムライン — 動きのある HUD を動画編集ソフトのように作る

GeoUI Builder（Blockbench のプラグイン）に、**動画編集ソフトのようなタイムライン**がつきました。HUD の要素（画像・数字・ゲージ）を
時間に沿って動かし、透かし、コマを送り、音を鳴らし、そのまま **統合版のアドオン** に書き出します。ゲームの中ではスクリプトの命令で再生・
一時停止・シークでき、osu! のような **音楽ゲームの判定**（押した時刻を当たり・外れに）まで入ります。

- プラグイン: **`bds/geoui/dist/geoui_builder.js`**（GeoUI Builder とタイムラインの 1 ファイル。`node bds/geoui/build.mjs` が作る）
- 中身: `bds/geoui/timeline/`（`PLAN.md` が全体の設計と、本物のゲームで確かめたこと）
- 見本: `bds/addons/geoui_rhythm`（osu! 風の HUD。`node bds/geoui/timeline/demo.mjs` が作る）

## 入れる

Blockbench（5.0 以上。5.2.2 で確かめた）→ **File → Plugins → Load Plugin from File** → `dist/geoui_builder.js`。
メニュー **GeoUI** の下の方にタイムラインの項目が増え、GeoUI のプロジェクトを開くとパネルが 3 つ出ます。

| パネル | 場所 | 中身 |
|---|---|---|
| **GeoUI タイムライン** | 下 | シーケンスの選択・再生の道具・ルーラー（タイムコードと小節）・トラックとクリップ・鍵・トランジション・音の波形・実体の列・マーカー・in/out |
| **GeoUI インスペクタ** | 右 | 選んだ物（鍵・クリップ・トラック・マーカー・実体・テンプレート・道・シーケンス）の欄。数の欄はラベルを横にドラッグ。イージングは曲線で |
| **GeoUI 実体** | 右 | テンプレートの実体（音符など）の表: 並べ替え・絞り込み（`x>0 template=…`）・貼り付け（表計算の TSV / CSV）・コピー・osu! の取り込み |

プレビューの上には、選んだ道（パス）の点と、再生位置のまわりの実体の位置が描かれます（ドラッグで動かせる）。

## 作り方

1. **シーケンス**: タイムラインの上の「＋」（または「シーケンスを作る」）。名前・長さ・コマ / 秒・終わったら（1 回・ループ・往復・最後で止める）・in / out はインスペクタで。
2. **トラック**: アウトライナーで要素（画像・数字・ゲージのボーン）を選び、**GeoUI → タイムライン: 選んだ要素のトラックを足す**。再生位置から 2 秒のクリップが付きます。
   右クリックの「トラックを足す」で空のトラックを足し、インスペクタで要素を選んでもよい。1 つの要素に 1 本（2 本目は書き出さず、そう言います）。
3. **クリップ**: トラックの空いた所をダブルクリック。端をドラッグで長さ、体をドラッグで移動（他と重ならない一番近い所へ）、Alt で吸い付きを外す。
   要素はクリップの間だけ出ます（クリップの外では隠れる。動画編集のレイヤーと同じ）。
4. **鍵**: クリップを選んで再生位置で **K**。インスペクタで x・y・大きさ（scaleX / scaleY）・回転・不透明度・値（数字）・量（ゲージ）・コマ（連番）・道の進み。
   値は数か式（`param.x`・`t`・`math.sin(t * 360)` など。Molang の math がそのまま使える）。イージングは 32 種と 3 次ベジェ（「曲線」で 2 点をドラッグ）。
5. **トランジション**: クリップの頭・尻に フェード・スライド（上下左右）・ズーム・ポップ（インスペクタ、または右クリック）。
6. **テンポ**: インスペクタの「再生位置にテンポを足す」（BPM・拍子。途中で変わってよい）。ルーラーに小節、格子に拍（1/1〜1/16）。吸い付きは拍・鍵・クリップ・マーカー・再生位置へ。
7. **プリセット**: インスペクタの下の「プリセット（再生位置へ）」: タイトル・名前のテロップ・点数のポップ・カウントダウン・通知・進むゲージ・点滅・揺れ・ヒットの弾け・コンボのポップ・判定の文字。

### たくさんの物（音符・弾・通知）: テンプレートと実体

同じ動きを何百回も出す物は **テンプレート**（インスペクタの「テンプレートを足す」）にします。テンプレートのトラックはテンプレートの要素
（原型。ゲームでは出ない）を動かし、**実体**（時刻と param: `x`・`y`・番号・色…）ごとに複製が出ます。テンプレートの時間は実体の時刻からの秒
（lead: 前から出る秒、tail: 後に残る秒）。実体の列の実体をダブルクリックでテンプレートの中を開き、Esc で戻ります。

- 書き出しでは、同時に出る数だけテンプレートのボーンを複製した「枠」に順に割り当てます。既定は **焼き込み**（実体を Molang に。見た目は
  クライアントの時計だけで動き、通信の遅れを受けません。16 個ずつの組と二分木の短い行で引くので、何千個でも 1 フレームの計算は数回の比べだけ）。
  2000 個を超え、param がすべて詰め方（pack: 24 bit）に入るテンプレートは **流し込み**（スクリプトが出る少し前に枠のプロパティへ入れる）。
- プレイヤーのプロパティはゲームの上限が 32 個で、GeoUI 本体が 11 個使います。タイムラインは再生の状態に 2 個（シーケンス・止め・世代を 1 個に、
  始める時刻）、当たり・外れに 8 枠で 1 個（枠ごとに 3 bit）、流し込みの枠ごとに 2 個。osu! の 300 個の譜面で合わせて 15 個です。
- **道（パス）**: 直線・ベジェ・Catmull・円弧（osu! の長さで等速）。プレビューの上で点をドラッグ、Ctrl+クリックで足す、Alt+クリックで消す。
  実体ごとの道（`@instance`）も持てます（osu! のスライダー）。ゲームでは実体ごとのアニメーション（`anim_time_update` で道の上の進みを渡す）になります。

### 当たり・外れ（判定）に答える

テンプレートのクリップに **trigger**（hit / miss で始まる: 弾け・×印）と **until**（hit で切れる: 円が消える）を付けると、ゲームの中の判定
（押した時刻）に答えます。プレビューでは上の「プレビューの当たり」で 当たり（オート: どれも時刻ちょうどに当たる）・外れ・なし を選べます。

### 素材

**GeoUI → タイムライン: 音・画像・連番を取り込む…**

- **音**（.ogg・.wav）: プロジェクト（.bbmodel）にしまい、自分の音のトラックに再生位置から置きます（波形つき）。.mp3 はプレビューだけ（ゲームでは鳴らない: .ogg に）。
- **画像**（.png 1 枚）: 画像の要素に。
- **連番**（.png を何枚も）: 番号の順に 1 枚のテクスチャ（格子）にまとめ、コマ（frame）で送る要素に。1 周するクリップ（シーケンスのコマ / 秒で）も付けます。

### osu! の譜面

**GeoUI → タイムライン: osu! の譜面を取り込む（.osu・.osz）…**（実体の表の「osu! を取り込む」も）。円・スライダー（往復・玉）・スピナー・
コンボの番号と色・テンポ・道が入ります。足りない要素は描いて足します（円と接近の輪は譜面のコンボ色のコマ、番号・弾け・×・スピナー・玉、
スライダーの体は全部を 1 枚のアトラスに）。.osz の音楽が .ogg ならそのまま音のトラックに（.mp3 はプレビューだけ: .ogg にして取り込み直す）。

## キー（タイムラインを押してから）

| キー | | キー | |
|---|---|---|---|
| Space | 再生・停止 | J / K / L | 逆再生 / 止める（クリップを選んでいれば鍵）/ 再生（もう一度で 2 倍） |
| ← → | 1 コマ（Shift: 1 拍） | Home | in の位置へ |
| , . | 前・次の鍵へ | K | 再生位置に鍵 |
| S | 再生位置で切る | Delete | 消す（Shift: 消して詰める） |
| Ctrl+D | 複製 | M | マーカー |
| I / O | in / out | 1〜6 | 拍の分け方（1/1〜1/16） |
| + / - | 広げる / 縮める | \ | 全体を見る |
| Esc | テンプレートから出る・選びを外す | 右クリック | 切る・複製・消す・フェード・鍵・マーカー・トラックを足す |

取り消し・やり直しは Blockbench の **Ctrl+Z / Ctrl+Y**（編集 1 回が 1 手。履歴に「GeoUI: クリップを動かす」などと出ます）。

## プレビュー

再生かシークで、プレビューは Animate のモードに入り（GeoUI のレイアウトのアニメーション）、その上にタイムラインの値を当てます。
値は書き出す Molang と同じ計算（`model.evaluate`。試験 `tests/tl-anim-offline.mjs` が 1/60 秒ごとに一致を確かめる）。不透明度とコマは
その要素だけの材質で、実体は複製（保存されない・出入りに合わせて作って消す）で見せます。音は WebAudio で、時刻は音の時計
（聞こえる音に絵が合う。ずれが溜まらない）。上の「ループ」で in / out をくり返します。

## 動画に書き出す

**GeoUI → タイムライン: 動画を書き出す…**（GeoUI → 画面を正面から見る の向きで写します）

- **WebM**（動画と音）: 実時間で作ります（範囲の長さだけかかる）。背景は 黒・緑（クロマキー）・白・透明（VP9 のアルファ）。
- **PNG の連番**（zip）: 背景は透明。1 コマ 1 枚と、コマ数の書き付け（frames.txt）。

## アドオンに書き出す

**GeoUI → アドオンを書き出す（.mcaddon）** に、シーケンスがあればタイムラインが入ります: RP にシーケンスごとのアニメーション・
pre_animation の Molang（時刻・鍵・イージング・トランジション・道・実体の枠）・複製したボーン・要素ごとの render controller（不透明度とコマ）
と fade のマテリアル・音（sound_definitions）、BP にプロパティと再生のスクリプト。**はみ出し・式を確かめる** に、Molang の長さ・枠・プロパティの数などの注意も出ます。

### ゲームの中で

```
/scriptevent geoui:play <シーケンスの番号か id> [始める秒]
/scriptevent geoui:pause      /scriptevent geoui:resume      /scriptevent geoui:stop
/scriptevent geoui:seek <秒>   /scriptevent geoui:offset <ミリ秒>（押した時刻をずらす: 端末の遅れの補正）
```

（`geoui` は設定の名前空間）。コマンドブロック・別のパックからは全員に、プレイヤーが打てばその人に。押す（ジャンプ・スニーク・アイテムを使う）と
近い実体を osu! の幅（300 / 100 / 50・外れ）で判定し、点数・コンボ・正確さ（x100）・体力を `geoui:v0`〜`v3` に（数字やゲージの値に使える）。
マーカーに event を書くと `/scriptevent geoui:marker <シーケンス>:<マーカー> <event>` が出ます。音のクリップは時刻に鳴り、一時停止・シーク・
停止で止まります。入り直したプレイヤーには、その時刻から送り直します。

## できないこと・まだ確かめていないこと（要実測）

本物のアプリで確かめた物（`bds/addons/geoui_probe*`、記録は [timeline/PLAN.md](timeline/PLAN.md)）:
- **不透明度**: ゲームは render controller の色の alpha を GeoUI の blend の材質では使わない。タイムラインは色のマスク（USE_COLOR_MASK）を
  持つ fade の材質で描き、それは効く（0 で消え、0.5 で半分透ける・テクスチャの半透明と掛け算）。GeoUI 本体の `alpha` プロパティは今も効かない
  ので、0 のときは大きさで隠す。
- **回転の向き**: 正の角度は画面で時計回り（Blockbench のプレビューと同じ）。
- **限度**: ボーン 600 本・自分の render controller 70 個・アニメーション 1200 個までは描かれた。それを超えると書き出しが注意を出す（その先は要実測）。
- **Molang の行**: 書き出しは 1 行 1000 文字・括弧 24 段より長い行を出さない（長い行は短い行に分ける）。その形・2000 個の実体の引き方は
  ゲームでそのまま動いた（`geoui_probe_m`）。それより長い・深い行（6000〜16000 文字・括弧 54 と 100 段）を入れた回は、アプリがその
  ワールドに入れなかった。
- **本物の大きさの譜面**: 300 個の譜面（`bds/addons/geoui_rhythm_big`: プロパティ 15 個・pre_animation 1109 行・変数 906 個）が、本物の
  アプリで最後まで動いた（再生・シーク・一時停止・止め）。時計・止め・不透明度も `geoui_probe_tl` で合った。
- **Molang の量**: 1 つの pre_animation で 61 万文字・4029 行（1 行 150 文字）、短い行なら 5029 行まで、最後まで動いた
  （`geoui_probe_sz`・`geoui_probe_lc`）。書き出しはそれを超えると注意を出す。300 個の譜面は 20 万文字、1000 個でも 43 万文字。

まだ確かめていない物:
- **変数の数**: エンティティの中で 3032 個目までは効いた（`geoui_probe_vc`）。3053 個目は値が合わなかった（`geoui_probe_m`。止まりは
  しない）。その間のどこかが限度らしい（`geoui_probe_vx` で細かく測る）。書き出しは、プレイヤーの分も込みで 3000 個を超えると注意を
  出す。300 個の譜面は約 910 個、1000 個でも約 1020 個（変数は実体の数ではなく、同時に出る枠の数で増える）。
- **1000 個の譜面**（`addon/geoui_rhythm_huge` の枝、3.2 MB のパック）: 本物のアプリが参加の時に「An error has occurred」を出して
  入れなかった（2 回。サーバーにはつながっていない）。300 個（1.4 MB）は最後まで動いた。パックの大きさのせいかは要実測。

決まっていること:
- **音**: ゲームの音は途中から鳴らせない（シーク・再開で頭を過ぎた音は鳴らない）。プレビュー・動画は途中からでも鳴る。
- **ループ**: loop・pingpong は回るたびに実体を流し込み直し、判定し直す。pingpong の戻り（時間が逆に進む所）は見えるが、判定と音は無い。
- **判定**: サーバーの tick（50 ms）刻み。押してから届くまでの遅れは `offset` で直す。
