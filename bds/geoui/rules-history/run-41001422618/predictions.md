# 予測（commit 35a341c の SPEC.md 17 章のまま）

### 2 本目の予測（回す前に書いた: `--batch geoui_web_probe,geoui_web`、ゲームの画面 2400 x 1080）

1 本目を受けて直したこと: 通り道を空にするのは空の通り道の題名（`~gu~0a`、`channel.js`）、送り直しは 10 秒ごと（GeoUI Web）・しない（探り）。
GeoUI Web のページとツールバーは二重の枠（今の絵を下へ → 2 tick 後に新しい絵を上へ: `runtime.js`）。

| 区切り | 確かめること | 予測 |
|---|---|---|
| clear | 空の通り道を送ると絵が消えるか | 消える（1.5 秒後に赤なし） |
| title | 普通の題名 HELLO が出るか（真ん中の帯の違い） | 出る（違い > 0.1 %） |
| timeout | 2・4・6 秒かかる絵 | 2 秒は出る、4 秒も出る、6 秒は出ない（待つのは 5 秒ほどと見る: 自信は低い） |
| under-slow | 下に赤、上に 3 秒かかる青（送り直しなし） | 1.5 秒後は下の赤、6.5 秒後は青 |
| frames-buffered | 二重の枠で 0.3 秒ごとに 40 枚（取得に 0.3 秒） | 3 枚の写真のどれも main に色がある（地面が見えない） |
| frames-plain | 一重の枠で同じ | 3 枚のうち少なくとも 1 枚は main が消えている（地面か色の一部） |
| f1-parts | F1 の 3 つの部分を 1 つずつ | API: ホットバーと十字が消え、手は残る。旗（`~gu~1a`）: ホットバー・会話が消える（十字は残る見込み）。プロパティ: 手と剣が消え（手の所の違い > 5 %）、戻すと手が戻る |
| f1-all | 全部（空の通り道で戻す） | F1 で全部消え、戻すとホットバー・手が戻る（戻した後の違いは腕の揺れだけ: 手の所 < 3 %、ホットバーの所 < 1 %） |
| web open | ブラウザが 20:9 の全画面に出るか（`make.mjs expect 2400x1080 g`） | ページ（青）が (0, 108)–(2400, 1080) に ±2 px、ツールバーが上の 108 px、ポインタの先の印（薔薇色）が (1200, 540) ±4 px |
| web pointer | 左寄せ 0.25 → 右スティック | 印が (600, 540) へ、スティックで右へ動く |
| web click | パッドの RT（腕の振り）でクリック | 色のページが次の色（紫 8000ff）に、紫が全面 |
| web back | スニーク（R3）を短く | 前の色（青）に戻る |
| web scroll | 左スティックを後ろ・RB（ホイール） | ページが下へ動く（違い > 10 %） |
| web dynamic | 動くページ（時計・アニメ） | 3 秒の間に絵が変わる（違い > 0.5 %: 時計とアニメの所） |
| web type | 欄を押して `/web:t Steve` | 題名が「入力フォーム — Steve」に（サーバーの GWEB page の行） |
| web site | ja.wikipedia.org・youtube.com | どちらも開き（GWEB page に wikipedia・youtube）、絵が出る（違い > 30 %） |
| web close | スニークを長く | 閉じて HUD に戻る（違い > 50 %） |
