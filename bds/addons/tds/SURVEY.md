# より良い地形を求める仕組み: 測量鳥と作戦卓（2026-11-08 作った）

ユーザーの依頼（2026-11-08 09:37）: 「より良い地形を求める何かを用意して欲しい。ただし簡単にできたら面白くないしランダムなのも面白くない。画期的なアイデアを採用して」

## 考え方
- **乱数ではない**: 鳥が行く先は、向いた方角と距離で決まる 1 点（64 ブロックの格子に丸める）。そこの土地は本物の世界のもの。平らな世界では、場所から決まる合成地形（`seedAt(x, z)`）。同じ向き・同じ距離なら、いつ誰が飛ばしても同じ土地。
- **簡単ではない**: 飛ばすには「測量の羽」が 1 枚要る。羽は勝って得る（初めは 3 枚、勝ち +2、10 ウェーブ以上で負け +1）。水や溶岩、建物があったり、道が通らなかったりしたら、羽は無駄になる。良い土地は少ない。
- **画期的な所**: 鳥が持ち帰るのは★だけではない。
  1. **作戦卓（砂盤）**: 訓練場の東どなりに、調べた土地の 1/4 の模型が立ち上がる。そこに実際に造られる階段の街道（赤）、入口と出口の門（灯り）、中央の拠点（焚き火）まで載る。出撃の前に、歩いて回りながら土地を見比べられる。模型が真実で、その場所へ出撃すると、模型のとおりの道ができる。
  2. **土地の傾きの手がかり**:「土地は北東へ高くなる」「水は南」。調べた 81×81 の高さから実際に出したもの。地形は続いているので、良い土地の近くには良い土地がある。手がかりを読んで、少しずつ良い土地へ寄せていく（山登り）。
  3. **地図が育つ**: 見つけた土地には、見つけた人の名前が残る（atlas）。同じ所はもう一度調べてもタダ（覚えていれば得）。エレベーターの行き先の候補には、作戦卓の土地が★付きで先頭に並ぶ。

## 「良い地形」の測り方（タワーディフェンスにとって）
道は土地に合わせて計画される（src/road.ts の planSteps。遠征と同じ seed と同じ手順なので、同じ道になる）。その道に対して:
- **要所** keys: 地面の置き場（道との高さの差が −2〜+1）のうち、道に被る長さがいちばん長い 5 か所の平均。被る長さ = 8 ブロック以内にある道の長さ。置き場どうしは 3 ブロック以上離す。曲がり角の内側やU字の間が高くなる。
- **高台** heights: 崖の置き場（道より 2 以上高い）のうち、いちばん長く被る 3 か所の平均。崖専用のタワーが 4 種類あるので重要。
- **足場** footing: 道から 4.5 以内にある地面の置き場の数。
- **★1〜5**: この 3 つから計算する。しきい値は合成地形 200 か所の分布で決める（tools/rate_test.mjs）。★5 はまれになるようにする。

## 遊び方
- `/tds:scout <距離> [角度]`: 向いている方角（または角度）へ鳥を放つ。距離は 1500〜6000。羽を 1 枚使う。同じ所はタダで、地図から答える。
- `/tds:feathers [n]`: 羽の数を見る（op は n に変えられる。テスト用）。
- `/tds:atlas`: 見つけた土地の一覧（★、名前、方角と距離、見つけた人）。
- `/tds:table`: 作戦卓へ移動する（x 40〜117、z −13〜13。訓練場から東へ歩いても行ける）。
- エレベーター（`/tds:queue`）: 候補の 3 つのうち、作戦卓の土地が先に入る。投票で選ばれた土地へは、まさにその場所へ出撃する。

## 実装の地図
- `src/road.ts`（純粋。node で試せる）: `synthLand(seed)`（平らな世界の合成地形の高さ。site.ts の synth はこれで書く）、`rate(t, rt)`（要所・高台・足場と★）。
- `src/site.ts`: `load(cx, cz, id)` / `freeArea(id)` に区域の名前を渡す（偵察は `tds_scout`。試合中の `tds_site` は外さない）。`survey(cx, cz, seed)` は、建てずに調べる: 読み込み → 走査 → 平らなら synthLand → 断る理由 → 道の計画 → rate。
- `src/scout.ts`（新規）: 羽（プレイヤーの動的プロパティ `tds:feathers`）、地図（ワールドの `tds:atlas`、最大 32 件）、作戦卓（`tds:table`: 3 枠、模型はジョブで建てる、看板に★と名前）、鳥の見た目（試合の速さが 1 で headless でないときだけ）、コマンド、試合の終わりの羽。
- `src/lobby.ts`: `candsFor` が作戦卓の土地を先に入れる。出発: 地図にある seed なら `expedition(mode, ps, { seed, at })`。
- tests.txt「## scouting」: 平らな世界で東へ 3000 → 報告と★、羽 3→2、同じ所はタダ、作戦卓のブロック、地図、エレベーターでその土地へ（site_built の x・z と、曲がり・橋・段の数が報告と同じ）、羽 0 は断る、再起動しても地図と作戦卓が残る。

## まだやらないこと（次の候補）
- 弓のように溜めて放つアイテム（溜めた長さで距離）。itemReleaseUse の useDuration を使う。
- 本物の世界で、調べた範囲の外の手がかり（読み込まれていないチャンクは読めない）。
- 本物の世界での★の分布（`LAB_WORLD=normal LAB_SEED=1` で何か所か飛ばす）。合成地形で合わせたしきい値が、山や森でも意味のある散らばりになるか。
