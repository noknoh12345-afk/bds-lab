# geoui_osu_pixel を本物のアプリで: 検証ツアー（/scriptevent geoui:tour: 円・スライダー・キアイ・HD・FL・スピナー・休み・ミス・失敗・結果を約 24 秒で）を
# 場面ごとに写し、全部を録る（GeoUI のタイムラインが描く osu!）。時刻はツアーを始めてからの目安（命令が届くまでの遅れがある）。比べる基準は再生前の画面（world--before-play）。

section title
launch
until title 600000
shot title

section join
join
until joined 900000
wait 3000
do time set noon
do gamerule dodaylightcycle false
do gamerule sendcommandfeedback false
do gamerule commandblockoutput false
do weather clear
do tp @a 0 -60 0 0 90
do hud @a hide paperdoll
do hud @a hide touch_controls
do hud @a hide hotbar
do hud @a hide crosshair
wait 6000
shot world--before-play
absent clientlog \bERROR\b

section tour
# (the whole tour recorded: recordings/rec-1.mp4 — the person's Discord gets it at the end, made to fit: app/lib/feed.mjs)
record start
do scriptevent geoui:tour
wait 1500
shot tour-01-circles
measure diff tour-01-circles 0 0 1560 720
wait 2000
shot tour-02-slider
measure diff tour-02-slider 0 0 1560 720
wait 2050
shot tour-03-kiai
measure diff tour-03-kiai 0 0 1560 720
wait 2450
shot tour-04-hidden
measure diff tour-04-hidden 0 0 1560 720
wait 2100
shot tour-05-flashlight
measure diff tour-05-flashlight 0 0 1560 720
wait 2600
shot tour-06-spinner
measure diff tour-06-spinner 0 0 1560 720
wait 1700
shot tour-07-break
measure diff tour-07-break 0 0 1560 720
wait 2550
shot tour-08-miss
measure diff tour-08-miss 0 0 1560 720
wait 1850
shot tour-09-fail
measure diff tour-09-fail 0 0 1560 720
wait 4400
shot tour-10-results
measure diff tour-10-results 0 0 1560 720
wait 2300
record stop
absent clientlog \bERROR\b

section stop
# (the tour stops by itself: nothing of the game left on the screen)
shot stopped
measure diff stopped 0 0 1560 720

section log-molang
# (a content error of Molang in the pack's own lines (geoui_): a pre_animation line the game cannot run stops the lines after it)
absent clientlog (?i)geoui_
