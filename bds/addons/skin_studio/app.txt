do fill -4 -60 12 4 -56 12 stone

section legs-zombie-relay
do difficulty normal
do gamemode survival @a
do effect @a resistance 60 255 true
do effect @a regeneration 60 255 true
do execute as @a run studio:debug on
do tp @a -9.5 -60 5.5 -90 0
do summon zombie 7.5 -60 5.5 90 0
do effect @e[type=zombie] fire_resistance 60 1 true
do camera @a set minecraft:free pos 0.5 -58.6 10.8 rot 20 0
wait 300
record start
do execute as @e[type=zombie] run tp @s ~ ~ ~ facing -9.5 -60 5.5
wait 5000
record stop                               # zombie: カメラは窓の前から斜め下、本物も窓の中の鏡像も画面に入る（中継・緑の点）。本物と鏡像の脚・腕の振れを並べる
do camera @a clear
do kill @e[type=zombie]
section legs-zombie-fallback
do tp @a -9.5 -60 5.5 -90 0
do summon zombie 7.5 -60 5.5 90 0
do effect @e[type=zombie] fire_resistance 60 1 true
do camera @a set minecraft:free pos 0.5 -58.4 11.6 rot 0 0
wait 300
record start
wait 5000
record stop                               # zombie: カメラはガラスのすぐ前で鏡だけを見る（本物は画面の外 → 予備・黄の三角）。中継の回と脚の振れを比べる
do camera @a clear
do kill @e[type=zombie]
do gamemode creative @a
do difficulty peaceful
do execute as @a run studio:debug off
