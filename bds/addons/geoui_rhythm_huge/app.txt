# geoui_rhythm_huge を本物のアプリで: 再生して、決まった時刻に写す（GeoUI のタイムラインが描く: 円・接近の輪・番号・スライダーの体と玉・スピナー・点数）
# 時刻は再生を始めてからの目安（サーバーの命令が届くまでの遅れがある）。比べる基準は再生前の画面（world--before-play）。

section title
launch
until title 600000
shot title

section join
join
until joined 300000
wait 3000
do time set noon
do gamerule dodaylightcycle false
do gamerule sendcommandfeedback false
do gamerule commandblockoutput false
do weather clear
do tp @a 0 -60 0 0 90
do hud @a hide paperdoll
do hud @a hide touch_controls
do hud @a hide hotbar
do hud @a hide crosshair
wait 6000
shot world--before-play
absent clientlog \bERROR\b

section play
# (the whole play recorded too: recordings/rec-1.mp4 — the person's Discord gets it at the end, made to fit: app/lib/feed.mjs)
record start
do scriptevent geoui:play 1
wait 2000
shot play-2s
measure diff play-2s 0 170 1030 720
wait 8000
shot play-10s
measure diff play-10s 0 170 1030 720
wait 20000
shot play-30s
measure diff play-30s 0 170 1030 720
wait 30000
shot play-60s
measure diff play-60s 0 170 1030 720
wait 60000
shot play-120s
measure diff play-120s 0 170 1030 720
wait 60000
shot play-180s
measure diff play-180s 0 170 1030 720
wait 60000
shot play-240s
measure diff play-240s 0 170 1030 720
wait 60000
shot play-300s
measure diff play-300s 0 170 1030 720
wait 50000
shot play-350s
measure diff play-350s 0 170 1030 720
wait 25000
shot play-375s
measure diff play-375s 0 170 1030 720
record stop
absent clientlog \bERROR\b

section seek-pause
do scriptevent geoui:seek 300
wait 1500
shot seek-300s
measure diff seek-300s 0 170 1030 720
do scriptevent geoui:pause
wait 1500
shot paused-a
wait 1500
shot paused-b
measure diff paused-b 0 170 1030 720
do scriptevent geoui:stop
wait 2000
shot stopped
measure diff stopped 0 170 1030 720
absent clientlog \bERROR\b

section log-molang
# (a content error of Molang in the pack's own lines: a pre_animation line that the game cannot run stops the lines after it —
#  the slots then never show. Only lines that name the pack's own variables (geoui_): the game's own vanilla player writes
#  Molang lines of its own (item_use, main_hand, holding, spear: geoui_probe_b, 2026-10-22), which are not this pack's)
absent clientlog (?i)geoui_
