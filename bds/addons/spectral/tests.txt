## play starts 48 sine voices and 8 noise bands as looping sound instances
@A cmd /spectral:play demo
~ @A ▶ Demo \(original\) — Spectral Player \(0:22, 48/48 voices, headphones\)
wait 1000
@A cmd /spectral:status
~ @A status: playing demo .* mode phones voices 48 instances 56 speed 1

## it plays in real time: 20 frames a second, a spectrum on the action bar
wait 2000
@A cmd /spectral:status
~ @A status: playing demo 0:0[2-4]/0:22 frame (4\d|5\d|6\d|7\d)/460
~ @A actionbar: [▁▂▃▄▅▆▇█]{24}

## pause holds the playhead, resume goes on
@A cmd /spectral:pause
~ @A ⏸ paused
wait 1200
@A cmd /spectral:status
~ @A status: paused demo
@A cmd /spectral:pause
~ @A ▶ resumed

## seek jumps to a time
@A cmd /spectral:seek 10
~ @A ⇥ 0:10
wait 600
@A cmd /spectral:status
~ @A status: playing demo 0:1[01]/0:22 frame 2[0-2]\d/460

## speed stretches time without changing pitch, 0 freezes, negative plays backwards
@A cmd /spectral:speed 0.5
~ @A speed 0.5x
@A cmd /spectral:seek 4
wait 2050
@A cmd /spectral:status
~ @A status: playing demo 0:0[45]/0:22 frame (9\d|10\d|11\d)/460 .* speed 0.5
@A cmd /spectral:freeze
~ @A ❄ frozen
wait 1000
@A cmd /spectral:status
~ @A status: frozen demo
@A cmd /spectral:freeze
~ @A ▶ thawed
@A cmd /spectral:speed -1
~ @A speed -1x
@A cmd /spectral:seek 12
wait 2050
@A cmd /spectral:status
~ @A status: playing demo 0:(09|10)/0:22 .* speed -1
@A cmd /spectral:speed 1
~ @A speed 1x

## layers, loop and the spectrum can be switched
@A cmd /spectral:layers false true
~ @A noise off, bursts on
@A cmd /spectral:layers true true
~ @A noise on, bursts on
@A cmd /spectral:viz
~ @A spectrum off
wait 400
@A cmd /spectral:viz
~ @A spectrum on
@A cmd /spectral:loop
~ @A loop on
@A cmd /spectral:seek 22.5
~ @A ⇥ 0:22
wait 1500
@A cmd /spectral:status
~ @A status: playing demo 0:0[0-2]/0:22
@A cmd /spectral:loop
~ @A loop off

## calibration programs for measuring a real client (tools/rig)
@A cmd /spectral:calib list
~ @A calib: voices \(\d+ s\), fade \(\d+ s\), timing \(\d+ s\), seek \(\d+ s\), pitch \(\d+ s\), stereo \(\d+ s\), mixer \(\d+ s\), throughput \(\d+ s\) · all
@A cmd /spectral:calib stereo
~ @A ▶ calib stereo \(7 s\)
until calib stereo done 15000
~ @A calib stereo done \(0 errors\)
@A cmd /spectral:calib nothing
~ @A no calibration program "nothing"
