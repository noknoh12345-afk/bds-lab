# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 44（tools/exp/queue/q44_speech_sentences.json、tools/exp/queue40.py）: 読み上げの文を増やす（かなの 12 文）。今まで 4 文だけで Whisper 0.19〜0.48（文で大きく違う）。12 文で物差しを太く（かなだけ: 読みの誤りなし）、4 文は 3D でも

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song s_kaze,s_mori,s_tomo,s_yoru,s_umi,s_hon,s_sora,s_kagi,s_ame,s_neko,s_ie,s_tetsu pack=tools/exp/packs/q40

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section sent_s_kaze
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 250 28 300 false 600
audio start st_s_kaze
do execute as @a run spectral:play s_kaze
wait 3653
do execute as @a run spectral:stop
audio stop
audio export st_s_kaze 160
