# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 103（tools/exp/queue/q103_talker_duck.json、11-18）: 話し手（ライブ、follow で 3 ブロック先の防具立て、日本語・英語）の横でサンプラーのバンド（ヘッドホン）。duck live on（話し手でもダッキング 12 dB、1.5.15）と off を on・on・off・off の並びで、話し手だけも。話し手の聞き取り（話し手だけの録音を当てはめ）と ViSQOL

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song speech_ja_soseki,speech_en_wordsworth suffix=_e pack=tools/exp/packs/run10

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0
do execute as @a run summon armor_stand talker 0 -60 3

section tl_none_ja
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 250 28 300 false 600 true true
do scriptevent spectral:room 0
do scriptevent spectral:duck 12
do scriptevent spectral:duck live off
do execute as @a run tp @s 0 -60 0 0 0
do tp @e[name=talker] 0 -60 3
audio start tlnone_ja
do execute as @a run spectral:live_demo speech_ja_soseki_e follow @s 24 "follow:talker"
wait 10000
do execute as @a run spectral:live demo_speech_ja_soseki_e stop
do execute as @a run spectral:stop
audio stop
audio export tlnone_ja 160
