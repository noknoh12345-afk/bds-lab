# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 41（tools/exp/queue/q41_long_mix_20min.json、tools/exp/queue40.py）: 混ぜて 20 分（サンプラー・読み上げ・ファイル・正弦波を順に）。曲を切り替えながら 20 分: 素の温め・捨て・正弦波の道との行き来が長く続いても崩れないか（後で曲ごとに区切って最初の周と比べる）

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song rock_big,vocal_name_of_love suffix=_e pack=tools/exp/packs/run10
audio song fur_elise,speech_hello,speech_cave pack=tools/exp/packs/notes

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section mix
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 250 28 300 false 600
