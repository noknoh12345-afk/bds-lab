# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 26（tools/exp/queue/q26_chords_wide.json、tools/exp/queue40.py）: 和音 4〜24 音（楽器を混ぜて）を 1 つの時刻・1.7 ms ずつ。p11 は同じ素の和音 12 音まで。楽器を混ぜ、同じ seek と別々の seek で 24 音まで: 電話が 1 tick に始められる数の天井

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song chord_mix,chord_spread pack=tools/exp/packs/q40

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section chord_same
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 250 60 300 false 600
audio start ch_same
do execute as @a run spectral:play chord_mix
wait 12300
do execute as @a run spectral:stop
audio stop
audio export ch_same 160
