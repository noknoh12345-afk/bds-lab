# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 32（tools/exp/queue/q32_ahead_3d.json、tools/exp/queue40.py）: 3D の先回り 0・100・250・400 ms。3D は作ってから 100〜200 ms 遅れて鳴る（推測）。先回りの量でクリックの間隔・エリーゼの揃い方がどう変わるか（既定 250 は実機で選んでいない）

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song clicks_pairs,clicks_pulse,fur_elise pack=tools/exp/packs/notes

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section ahead_0_pp
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 0 28 300 false 600
audio start ah0_pp
do execute as @a run spectral:play clicks_pairs speaker
wait 7500
do execute as @a run spectral:stop
audio stop
audio export ah0_pp 160
