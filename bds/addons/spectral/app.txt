# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 51（tools/exp/queue/q51_file_warm.json、tools/exp/queue40.py）: ファイルの曲の温め 0・300・600・1000 ms（ヘッドホン・3D）。ファイルの曲も部分ごとに温める: 部分の継ぎ目の遅れ・抜けが温めの長さでどう変わるか（p03 は温めの前）

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section file_w0
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 250 28 300 false 0
audio start fw0_phones
do execute as @a run spectral:play piano_file
wait 24500
do execute as @a run spectral:stop
audio stop
audio export fw0_phones 160

section file3_w0
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100

do execute as @a run spectral:play piano_file speaker
wait 24750
do execute as @a run spectral:stop
