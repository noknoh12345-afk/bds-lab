# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして
#   実行の成果物の public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# p01（tools/exp/queue/p01_sampler.json、tools/exp/sampler_plans.py）: サンプラー（MIDI を楽器の音で）を実機で。seekTo で tick の中に1 ms で置けるか（クリックの 2 発・37 ms の連打、束ねる 4 / 1 / tick に縛る、ヘッドホンと 3D）、ピアノ（エリーゼのために・エチュード）を置く／tick に縛る

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song clicks_pairs,clicks_pulse,fur_elise pack=tools/exp/packs/notes

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0
