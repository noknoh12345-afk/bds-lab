# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして実行の成果物の public/spectral/rec/ に公開する（鍵なし: 管理パネルでサインインして聞ける・
#   notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# 11 回目（tools/exp/make_app.py tools/exp/app11.json）: **まとめて録る**（batch 13: 1 本の録音に 13 曲まで、曲ごとに audio mark、
#   audio stop が目印で切り分け、audio analyze-all が並行して測る）。曲は前もって変換したもの（tools/exp/packs/run9・run10）。
#   d_ = いまの既定（ファイルより +6 dB）。9・10 回目と同じデータ
#   e_ = 同じ変換を +10 dB で詰めて **+10 dB で**鳴らす（10 回目は腕ごとの命令が抜けて +6 dB で鳴った: make_app.py を直した）
#        — d_ と曲ごとに交互に
#   ka_ / kb_ / kc_ = d_ の夏目漱石をライブの道で、聞く人それぞれの 3D の音（near）で左 3 / 12 / 24 ブロックから（南を向いて: 左が +x）。
#        距離と大きさ・左右（10 回目の kl_ は 6 ブロック）
#   c_ = 天井（元の音をそのままゲームに鳴らさせたもの、音量 1）13 曲: 同じ run の天井
