# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして実行の成果物の public/spectral/rec/ に公開する（鍵なし: 管理パネルでサインインして聞ける・
#   notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# キュー 10（tools/exp/queue/q10_live_10min.json）: ライブの道で 10 分（話し声と歌）。ボイスチャットの道（1 フレームずつ）を 10 分続ける: ジッターバッファ・ずれ・抜けが時間とともに増えないか

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song speech_10min pack=tools/exp/packs/live10

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section live10
audio start lv_speech_10min
do execute as @a run spectral:live_demo speech_10min phones @s 24
wait 605000
audio stop
audio export lv_speech_10min 96
