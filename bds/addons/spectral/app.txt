# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 62（q31 のやり直し: q31 は 2 回とも全録音が Opus にできなかった。tools/exp/queue/q62_bundle_warm_again.json、tools/exp/queue40.py）: 束ね 1・2・3・4（温めあり）。p01・p04 は温めなしで束ね 2 を選んだ: 温めありでも 2 が一番か（落ちていた音は温めで戻る）

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song fur_elise,clicks_pulse pack=tools/exp/packs/notes

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section bundle_1_fe
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 1 250 28 300 false 600
audio start bw1_fe
do execute as @a run spectral:play fur_elise
wait 15200
do execute as @a run spectral:stop
audio stop
audio export bw1_fe 160
