# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして実行の成果物の public/spectral/rec/ に公開する（鍵なし: 管理パネルでサインインして聞ける・
#   notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# 10 回目（tools/exp/make_app.py tools/exp/app10.json）: 曲は前もって変換したもの（tools/exp/packs/run9・run10: クライアントの模型で採点したデータそのもの）。
#   d_ = 9 回目の新しい既定（ファイルより +6 dB）。9 回目と同じデータ: run をまたいだばらつきも測る
#   e_ = 同じ変換を +10 dB で詰めて +10 dB で鳴らす（エミュレーターでは 13 曲中 9 曲で上・中央値 +0.02・平均 +0.16、クリップの歪みは推測で話し声 −21 dB）
#        — d_ と曲ごとに交互に（40 分で切れても組が残る）
#   kl_ / kr_ = d_ の夏目漱石をライブの道で、聞く人それぞれの 3D の音（near: follow と同じ鳴らし方）で左 6 ブロック / 右 6 ブロックから
#        （南を向いて: 左が +x）。lr_db が左右の差。9 回目の jl_ / jr_（全員で 1 組の 3D スピーカー）と比べる
