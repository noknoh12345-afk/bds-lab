# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして tools/rig/rec_public.pem で暗号化した `[spectral rec]` の行（tools/rig/rec_decode.mjs で開く）。
# 7 回目（tools/exp/make_app.py で作成）: 出荷版と最終の既定を同じ run で。
#   s_ = 出荷版の変換（residual all・フェードなし・形式 1）を電話の 24 声・打撃音 1 tick 先・レベル 0 で 13 曲
#   w_ = 最終の既定（residual voiced・tick ごとに合わせたフェード・形式 2、電話の既定: 24 声・打撃音なし・+6 dB を setVolume で）13 曲
#   u_ = w と同じで +10 dB（エミュレーターでは +6 → +10 dB でドラム 1.95 → 2.83 ほか。ただしクリップの歪みが −21〜−44 dB に）6 曲
#   f_ = w と同じ曲データをレベル 0 で 4 曲（+6 dB の分を分けて見る。5 回目の b_ と比べるとフェードの分）
#   q_ = 天井を playSound の音量 2（+6 dB: w_ と同じ大きさ。ミックスは約 2 でクリップする）13 曲。音量 1 の天井 c_ は前の run の録音
