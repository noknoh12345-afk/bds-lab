# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音は app/runs/<実行>/audio/*.wav（封じた成果物）。
#   数はジョブのログの `[spectral rig] <録音> <何>: {...}` の行（audio analyze が出す。公開のリポジトリでも数だけは見える）。
# 試験曲: audio song がここで変換してコンソールから spectral:song で送り、/spectral:play で鳴らす（g_<曲>）。
# 天井: audio ceiling が元の抜粋を OGG のまま鳴らすだけのアドオン（bds/addons/spectral_ceil、実行の場で作る・コミットしない）を
#   作り、addon で BDS をそれで起動し直して入り直し、同じクライアント・同じ録音で鳴らす（c_<曲>）。天井との差 = 両方の ViSQOL の差。
# 一度で 40 分に収まるよう曲は 2 組に分ける（SONGS_A: ここ、SONGS_B: 下の注釈）。重い変換は join の前、解析は録音の後ごと。

section title
launch
until title 600000
shot title

section prep
audio song piano_gymnopedie
audio song vocal_stars
audio song drums_round
audio song rock_big
audio song edm_detection
audio song orchestra_five_armies
audio song speech_en_wordsworth
audio ceiling spectral_ceil piano_gymnopedie,vocal_stars,drums_round,rock_big,edm_detection,orchestra_five_armies,speech_en_wordsworth

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear

section calib
audio start calib
do spectral:calib all
until server spectral calib\] end throughput 300000
wait 2000
audio stop
audio analyze calib all

section demo
audio start demo
chat /spectral:play demo
wait 27000
audio stop
audio analyze demo song:demo
