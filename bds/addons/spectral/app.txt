# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音は app/runs/<実行>/audio/*.wav（成果物には入らない）。
#   数はジョブのログの `[spectral rig] <録音> <何>: {...}` の行（audio analyze）。録音そのものは `audio export` が Opus にして
#   tools/rig/rec_public.pem で暗号化し `[spectral rec]` の行でログへ（開けるのはその秘密鍵の持ち主だけ: tools/rig/rec_decode.mjs）。
# 音量: audio volume がメディアの音量を最大・ゲームの audio_ を 1（BGM 0）に（既定のままでは録音が元より約 39 dB 小さかった）。
# 試験曲: audio song がここで変換してコンソールから spectral:song で送り、execute as で /spectral:play。
# 3 回目: 13 曲を、電話の新しい既定（同時発音数 32 に収まる 24 声 + ノイズ 8: m_）と軽量モード（16 声: l_）で。天井（c_）は
#   run 41068618513・41076646541 で全曲を録ってある（同じ端末・同じ録り方）。天井を録るなら: audio ceiling spectral_ceil <曲,…> →
#   section の頭で addon spectral_ceil・join・until joined → 曲ごとに do scriptevent spectral:ceiling <曲>（その前の版の app.txt）。

section title
audio info
stop
audio volume 0
launch
until title 600000
