# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 69（tools/exp/queue/q69_sampler_distance.json、q29 のやり直し: 11-05 の録音が解く前に期限で消えた）: サンプラーの 3D: 距離 0〜32 ブロック。q04 は正弦波の道で 8 ブロックまで同じ。サンプラー（ピアノ・読み上げ）は 3D の遠さでどう落ちるか

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song fur_elise,speech_hello pack=tools/exp/packs/notes

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section dist_0_fe
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 250 28 300 false 600
do execute as @a run tp @s 0 -60 0 0 0
audio start sd0_fe
do execute as @a run spectral:play fur_elise speaker
wait 700
do tp @a 0 -60 0
wait 14750
do execute as @a run spectral:stop
do execute as @a run tp @s 0 -60 0 0 0
audio stop
audio export sd0_fe 160
