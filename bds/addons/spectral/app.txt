# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして実行の成果物の public/spectral/rec/ に公開する（鍵なし: 管理パネルでサインインして聞ける・
#   notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# 20 回目（tools/exp/make_app.py tools/exp/app20.json）: ライブの変換に合成による分析をその場で（web/live.js LiveRefiner、2 フレーム先まで見る =
#   遅れ +100 ms）。ライブの変換のまま（_lb）と分析つき（_lr）を、ライブの道でヘッドホンに（spectral:live_demo … phones）。曲ごとに
#   za_（そのまま）→ zb_（分析つき）→ zc_（分析つき）→ zd_（そのまま）。曲は tools/exp/packs/live20（tools/live/encoder.mjs --refine 2）
#   それから歩く話し手（17–19 回目と同じ道、0.01）: zf_ / zi_ = 1.5 ブロックで作り直す（既定）、zg_ / zh_ = 3 ブロックで
