# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 64（tools/exp/queue/q64_sampler_voices.json、q25 のやり直し: 11-05 の録音が解く前に期限で消えた）: サンプラーの同時音数 8・16・28・40・60。既定の 28 は電話の 32 音から決めただけ。ピアノのエチュードとバンドで、少ないと切れる・多いと電話が落とすの間のどこが一番か

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section voices_8_pd
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 250 8 300 false 600
audio start vc8_piano_demo
do execute as @a run spectral:play piano_demo
wait 21200
do execute as @a run spectral:stop
audio stop
audio export vc8_piano_demo 160
