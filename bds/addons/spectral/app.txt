# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして tools/rig/rec_public.pem で暗号化した `[spectral rec]` の行（tools/rig/rec_decode.mjs で開く）。
# 6 回目（tools/exp/make_app.py で作成）: ファイルより大きく鳴らせるか、と tick ごとに合わせたフェード。ゲームはどの音もファイルより
#   32.5 dB 小さく 16 bit で鳴らすので静かな曲の天井は量子化で決まる（エミュレーター: +12 dB で天井の中央値 3.11 → 3.90）。
#   calib loud = setVolume 0.125〜8 と、定義の音量 4 の音（spectral.osc_v4）の実際の大きさ
#   f_ = 改良版＋フェードを元の 10 ms の包絡に合わせる（変換器 nz_fade・v_fade）6 曲、h_ = f と同じ＋/spectral:level 12（setVolume）13 曲、
#   k_ = h を音量 4 の音（_l）で 2 曲、q_ = 天井を playSound の音量 4 で 10 曲、e_ = 天井を定義の音量 4 の音で 2 曲（同じ大きさの天井）
