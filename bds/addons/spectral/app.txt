# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして実行の成果物の public/spectral/rec/ に公開する（鍵なし: 管理パネルでサインインして聞ける・
#   notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# 22 回目（tools/exp/make_app.py tools/exp/app22.json）: その場の合成による分析（20 回目でヘッドホン +0.26）は 3D でも効くか。曲は 20 回目の
#   tools/exp/packs/live20（_lb ライブのまま / _lr 分析つき）。3 ブロック前に止まった話し手（follow、名札の防具立て）: 曲ごとに ba_ → bb_ → bc_ → bd_
#   （そのまま・分析・分析・そのまま。最初に bg_ = 話し手を置いて夏目漱石をそのまま 1 本）、それから左 24 ブロックの near で be_ / bf_（そのまま / 分析）

launch

do time set noon

section bg
do execute as @a run tp @s 0 -60 0 0 0

do execute as @a run spectral:handover hold 1.5 2 0 8
do execute as @a run summon armor_stand talker 0 -60 3
audio start bg_1
audio mark bg_speech_ja_soseki
do execute as @a run spectral:live_demo speech_ja_soseki_lb follow @s 24 "follow:talker"
wait 23000
audio stop
audio analyze-all bg_speech_ja_soseki=song:speech_ja_soseki
audio export bg_speech_ja_soseki 160
