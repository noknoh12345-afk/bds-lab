# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして実行の成果物の public/spectral/rec/ に公開する（鍵なし: 管理パネルでサインインして聞ける・
#   notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# キュー 19（tools/exp/queue/q19_pause_seek.json）: 一時停止・再開・シーク（6 曲）。リモコンの一時停止と ±10 秒を実機で: 継ぎ目のプツッ・音が戻るまでの時間

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song speech_ja_soseki,vocal_name_of_love,orchestra_five_armies,rock_big,piano_gymnopedie,edm_detection suffix=_e pack=tools/exp/packs/run10

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section pause
audio start ps_speech_ja_soseki
