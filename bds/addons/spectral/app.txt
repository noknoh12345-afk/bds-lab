# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 43（tools/exp/queue/q43_speech_mora.json、tools/exp/queue40.py）: 読み上げの速さ（1 モーラ 140・160・180・200・220 ms）。手元の Whisper は 180 ms が一番だった（推測）。実機で、速いと素の頭が重なって潰れるか・遅いと間延びか

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song speech_hello_m140,speech_cave_m140,speech_hello_m160,speech_cave_m160,speech_hello_m200,speech_cave_m200,speech_hello_m220,speech_cave_m220 pack=tools/exp/packs/q40
audio song speech_hello,speech_cave pack=tools/exp/packs/notes

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section mora_140_hello
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 250 28 300 false 600
audio start mo140_speech_hello
do execute as @a run spectral:play speech_hello_m140
wait 4949
do execute as @a run spectral:stop
audio stop
audio export mo140_speech_hello 160
