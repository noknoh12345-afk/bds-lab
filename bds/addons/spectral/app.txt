# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして実行の成果物の public/spectral/rec/ に公開する（鍵なし: 管理パネルでサインインして聞ける・
#   notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# キュー 18（tools/exp/queue/q18_loop_5min.json）: 1 曲をループで 5 分。/spectral:loop で同じ曲を 15 周: 周の継ぎ目と、時間が経っても音が崩れないか

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song vocal_name_of_love suffix=_e pack=tools/exp/packs/run10

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section loop
do execute as @a run spectral:stop
audio start lp_vocal_name_of_love
do execute as @a run spectral:loop
do execute as @a run spectral:play vocal_name_of_love_e
wait 300000
do execute as @a run spectral:stop
do execute as @a run spectral:loop
audio stop
audio export lp_vocal_name_of_love 160
