# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。録音そのものは `audio export` が Opus にして実行の成果物の
#   public/spectral/rec/ に公開する（notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。1 録音 = 1 区切り（失敗はその録音だけ）
# キュー 65（tools/exp/queue/q65_warm_min.json、q22 のやり直し: 11-05 の録音が解く前に期限で消えた）: 温めの最短（0・20・50・80・110・150 ms）。p13 は 150 ms 前で 12/12・0 で 0/12。その間のどこから鳴るか（短いほど曲の頭を待たせない）。最後に 0 ms の組をもう一度（読み込み済みなら全部鳴る: 物差し）

section title
audio info
stop
audio volume 0
launch
until title 600000
audio info
shot title

section prep
audio song probe_m0,probe_m20,probe_m50,probe_m80,probe_m110,probe_m150 pack=tools/exp/packs/q40

section join
join
until joined 300000
wait 5000
do time set noon
do gamerule dodaylightcycle false
do weather clear
do execute as @a run tp @s 0 -60 0 0 0

section warm_m0
do execute as @a run spectral:pitch 0
do execute as @a run spectral:speed 1
do execute as @a run spectral:volume 100
do execute as @a run spectral:sampler 2 250 28 300 false 0
audio start wm_m0
do execute as @a run spectral:play probe_m0
wait 13850
do execute as @a run spectral:stop
audio stop
audio export wm_m0 160
