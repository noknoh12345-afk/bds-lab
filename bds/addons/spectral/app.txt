# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして実行の成果物の public/spectral/rec/ に公開する（鍵なし: 管理パネルでサインインして聞ける・
#   notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# 14 回目（tools/exp/make_app.py tools/exp/app14.json）: 3D の音のレベル（/spectral:range 3 <dB>）。遠くでは話し声の静かな所が 16 bit の床に消える
#   （12 回目: 24 ブロックで元の −40〜−50 dB の所の 3–4 割がデジタルの 0）ので、ヘッドホンの +10 dB と同じことを 3D にも。夏目漱石をライブの道で、
#   聞く人ごとの 3D（near）で左に: la_ / lb_ / lc_ = 3 ブロックで 0 / +6 / +10 dB（近くでクリップしないか）、ld_ / le_ / lf_ = 24 ブロックで 0 / +6 / +10、
#   lg_ / lh_ = 46 ブロックで 0 / +10。ls_ = 曲のスピーカー（spectral:play … speaker、その場で: 1.2.0 の Session の 3D の作り方の頭）
#   mg_ = 話す人を名札「talker」の防具立てにして follow（3 ブロック前、止まったまま）、mf_ = 同じ防具立てを 0.5 秒ごとに 1 ブロックずつ左右に
#        （3 ブロック前を x = 6 … −6 で往復、約 1 秒ごとに音の作り直し = 1.2.0 の引き継ぎ）: 動く話す人の音が途切れたり「ピッ」と鳴ったりしないか

audio info
stop

launch
until title 600000

do time set noon

do weather clear

section la
do execute as @a run tp @s 0 -60 0 0 0
do execute as @a run spectral:range 3 0
audio start la_1
audio mark la_speech_ja_soseki
do execute as @a run spectral:live_demo speech_ja_soseki_d near @s 24 "near:3,-58.5,0,overworld"
wait 23000
audio stop
audio analyze-all la_speech_ja_soseki=song:speech_ja_soseki
audio export la_speech_ja_soseki 160
