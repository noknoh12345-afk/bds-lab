# Spectral Player の測定リグ（本物のクライアントが鳴らした音を録る）: node lab.mjs app run -a spectral --device redroid
#   GitHub では Actions → redroid → Run workflow（addon: spectral, mode: run）。数はジョブのログの `[spectral rig]` の行、録音そのものは
#   `audio export` が Opus にして実行の成果物の public/spectral/rec/ に公開する（鍵なし: 管理パネルでサインインして聞ける・
#   notify.yml が Discord に送る・tools/rig/fetch_rec.py <run> で取る）。
# 12 回目（tools/exp/make_app.py tools/exp/app12.json）: まとめ録り（batch 13）。曲は前もって変換したもの（tools/exp/packs/run9・run10・run12）。
#   d_ = いまの既定（+6 dB）・f_ = 同じ変換を +8 dB で詰めて +8 dB で・e_ = +10 dB で詰めて +10 dB で — 曲ごとに d・f・e の順に交互
#        （11 回目: +10 dB は 10/13 で上、話し声と歌だけ少し下: +8 dB がその間を取れるか）
#   ra_ / rb_ / rc_ = d_ の夏目漱石をライブの道で、聞く人ごとの 3D（near）で左 24 ブロックから、3D の音を作る音量 1 / 2 / 4（spectral:range）
#   rd_ = 同じものを左 40 ブロックから、音量 4。11 回目: 音量 1 では 24 ブロックで無音
