# 予測（commit c9ed981 の SPEC.md 17 章のまま）

### 4 本目の予測（回す前に書いた: `--batch geoui_web_probe,geoui_web`）

3 本目を受けて直したこと: 通り道の題名は時間なし（fade in 0・stay 0・fade out 0: その題名の部品はすぐ終わり、次の普通の題名は新しい
部品で出る）、2 tick 後にゲームの題名の時間（10・70・20）を `/title @s times` で戻す（時間を付けない `/title` のため: R10.16）。F1 は腕
（rightarm・leftarm）を 100 単位下へ動かし、大きさも 0（持ち物は大きさ 0）。携帯（タッチ）では F1 の旗を送らない（`root_panel` の中の
操作ボタンを残す: R10.12）。探りには 1 人称の手の消し方を 1 つずつ試す実験（`gwp:fx 1` = 大きさ 0 だけ、`gwp:fx 2` = 下へだけ、青い羊毛
= プロパティなしで下へ）。

| 区切り | 確かめること | 予測 |
|---|---|---|
| title-chan | 通り道の題名（左に緑の絵） | 見えない（真ん中の帯 0 %） |
| title-plain | その後の `/title @a title HELLO`（時間を付けない） | **出る**（真ん中の帯の違い > 0.1 %） |
| title-api | API の HELLO（fade in 0・stay 200） | 出る |
| title-old | 前のやり方（通り道の題名に 30 秒）の後の HELLO | 出ない（R10.14 の仮説どおりなら）: 自信は中 |
| wool-scale | `fx 1`: 腕と持ち物の大きさ 0 だけ | 赤い羊毛は消えない（3 本目と同じ） |
| wool-move | `fx 2`: 腕を下へだけ | **赤が消える**（右下の赤 < 1000 px） |
| wool-arm | F1 のプロパティ（下へ・大きさ 0・描き方） | 赤が消える。`part arm 0` で戻る |
| blue-held | 青い羊毛（プロパティなしで下へ） | 青が見えない: プロパティが 1 人称に届かない時の切り分け |
